# v0.1.0 — 구현 범위

## 구현 완료

- Godot 4.6.3 프로젝트와 Windows x86_64 실행 파일.
- 18세 선수 생성: 이름·기본 스타일 3종·색상 3종·국적 표시·초기 능력치.
- 4주 × 주요 훈련/보조 훈련/생활: 개별 선택, 5개 기본 일정, 사용자 일정 저장 1개.
- 7개 능력치·성장·피로·컨디션·휴식·매주 자연 회복, 12개월마다 나이 증가.
- 훈련비·알바 2종·생활비·체육관비·현금 계산, 월말 미리보기·월간 결과·자금 부족 처리.
- 상대 분석, 5개 전략, 시드 기반 3라운드 MMA 자동 경기, 3개 포지션 전환, KO/TKO·서브미션·판정·무승부.
- 경기 수당·전적·상세 로그·경기 간격·월간 기록.
- 로컬 자동/수동 저장·불러오기·스키마 검증·이전 정상 저장 백업 및 복구.
- UI/성장/경기/저장 계산 분리. 선수 고유 ID와 영구 데이터 영역 분리.
- 실제 렌더링 화면 테스트, 수천 회 경기 시뮬레이션, 장기 진행·저장 테스트.

## 아직 구현하지 않음

- Android APK 생성·서명·실기기 검증. 프로젝트 UI와 방향은 Android 세로 기준으로 설정.
- 해외 단체·랭킹·계약·스폰서·타이틀·세계 챔피언 커리어.
- 유도·주짓수·노기 전문 대회, 세부 기술 숙련·부상·재활 시스템.
- 은퇴·명예의 전당 처리·LP 획득/소비·스페셜 계승·코치 전직·체육관 설립 효과.
- 관계·연애·인생 이벤트·재능/잠재력·성향·정교한 외형 편집.
- 정식 아트·애니메이션·음악/효과음·실시간 액션 경기。
- 실제 결제·광고·온라인 계정·클라우드 저장·스토어 배포。
- 완성된 경기 밸런스, 실제 심판 3인 판정, 다개월 자동 진행, 복수 저장 슬롯, 다른 버전 세이브 변환。

세부 가정은 루트의 `ASSUMPTIONS.md`, 검증 결과는 `docs/TEST_REPORT.md`에 기록한다.
