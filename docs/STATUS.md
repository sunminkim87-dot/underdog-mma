# v0.2.0 — 화면·진행·온라인 기반 개편

## 이번에 동작하는 기능

- 오프닝 로비: 새 선수, 이어하기, 명예의 전당, 훈련소 업그레이드, 캐시 상점, 서버 연결.
- 오리지널 체육관·편의점·숙소·강변 배경과 16프레임 캐릭터. 복싱·웨이트·달리기·그래플링·알바·수면·멘탈·배달 장면.
- 4주 × 주요/보조/생활 카드식 일정표, 행동별 비용·피로·회복량, 선택 미리보기에서 최대/실제 회복과 전후 수치.
- 월간 행동 장면 순차 재생, 활력·피로 게이지 보간, 성장·현금 변화, 배속·건너뛰기, 성장 리포트.
- 경기 예정 월 도달/초과 시 월 진행 차단. 홈/일정/계산 함수/서버가 같은 규칙을 적용. 경기 후 재개.
- MMA 상대 비교·자동 경기·라운드 점수/체력 게이지·상세 로그.
- 18개월 + 공식 경기 3회 이후 은퇴 정산. 명예의 전당 기록과 LP, 새 선수에게 유지되는 시설 3종 × 3단계와 실제 성장 보너스.
- 기존 P0 로컬 테스트 세이브 호환, 별도 온라인 캐시 저장. 원본 v0.1 다운로드 ZIP 보존.
- 개발용 서버: 익명 게스트, 계정별 SQLite 저장, 서버 권한 행동 계산, 서버 경기 시드, 충돌/재전송/동시 요청 보호, 재화 직접 제출 거부.
- 실제 HTTP로 Godot와 개발 서버를 연결한 통합 검증. 캐시 검증기 경계·중복 구매 지급 방지 테스트.

## 아직 동작하지 않는 실제 서비스 기능

- 운영 서버 호스팅/HTTPS 도메인 배포. 이 배포의 기본 Windows 플레이는 '개발 테스트'로 명시한다.
- Google Play 개발자 계정/상품/Android Billing/실제 영수증 검증/가격/결제 완료. 캐시 구매 버튼은 비활성화되어 있다.
- Google/Apple 영구 계정 로그인·기기 이전·게스트 복구, 운영용 보안 저장소·환불/취소 통지·스토어 배포.
- Android APK·실기기, Windows 디지털 코드서명과 네이티브 실행 검증.
- 은퇴 코치/선수 설립 체육관, 해외 커리어·전문 종목 대회·부상·이야기·음악/효과음.

캐시 상점이 있다고 실제 결제가 된다는 뜻은 아니다. 서버 코드가 있다고 운영 온라인 서비스가 배포됐다는 뜻도 아니다. 해당 경계는 로비·상점·서버 문서에 표시한다.
