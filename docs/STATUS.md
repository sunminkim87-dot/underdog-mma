# v0.3 초안 — 구현 범위

## 동작하는 기능

- 18세 선수 생성: 5개 출신 베이스, 총 능력치 184의 동일 예산. 기존 세이브의 능력치·현금·고유 ID 유지.
- 세로 화면 로비·4주 × 3슬롯 일정·월간 행동 장면·수치 리포트·체력/피로/실제 회복 게이지.
- 구별되는 컬러 아이콘과 복싱/킥복싱/레슬링/유도/주짓수 장면, 알바 장소 4종 추가.
- 알바 7종(기본 5, 이벤트 해금 2), 이벤트 13종, 성인 등장인물 3명과 친구·연인 선택/친밀도/일정/친구로 돌아가기.
- 훈련 횟수와 공식 경기 경험 조건의 이벤트 특별 기술 5종, 전투 능력치 보너스.
- 게임 현금 아이템 6종(회복 2, 장비 4): 구입·재고·사용·착용·해제·실제 경기 효과. 회복은 남은 피로만큼, 월 3회.
- 업적 6종, 계정당 최초 1회 물품 보상. 회복 아이템 재생성 반복 획득 방지.
- 경기 월 도달/초과 시 다음 달 차단, 기본 MMA 자동 경기·시드·경기 전 장비/기술 보너스 스냅샷.
- 18개월 + 공식 경기 3회 후 은퇴 정산, 명예의 전당·LP·시설 3종 × 3단계. 다음 선수에게 계정 자산 유지.
- 저장/불러오기/정상 백업 복구, 기존 v1 세이브에 필드만 추가하는 마이그레이션.
- 개발 서버의 계정 저장·서버 권한 계산·동시 요청/재전송 방지. 아이템/기술/이벤트/관계도 서버에서 검증.
- 연결창을 닫는 중 응답 도착 시 오류 방지. 재실행 시 서버 계정 자동 이어하기, 연결 실패 시 임의 로컬 전환 방지.

## 아직 구현하지 않은 것

- 대형 분기 스킬트리·기술 연출/전술 AI 자체 변화. 지금 특별 기술 효과는 경기 능력치 보너스다.
- 풍부한 연애 이야기·동거/결혼·추가 등장인물·장기 랜덤 사건·다양한 기술 단계.
- 은퇴 선수의 코치 전직/고용·체육관 설립·스페셜 계승. 초보 지도 알바는 이들과 별개다.
- 운영 온라인 서버 호스팅/HTTPS 배포·영구 로그인/기기 이전/계정 복구·운영 보안/부하 검증.
- Google Play 개발자 계정/Android Billing/실제 상품/가격/Google 영수증 검증/실제 결제/광고.
- Windows 디지털 코드서명·Windows OS 직접 실행·Android APK/실기기 검증, 음악/효과음.

기본 배포는 명시적인 개발 플레이 테스트다. 운영 온라인 서비스나 실제 결제가 제공된다고 표시하지 않는다. v0.1·v0.2 프로젝트와 다운로드 ZIP은 보존한다.
