# 화면 흐름 참고

사용자 요청에 따라 더 루키: 고교야구선수 키우기의 공개 자료를 확인했다.

- 공식 가이드: https://play.therookielab.app/guide
- 공식 소개: https://play.therookielab.app/
- 공개 홈 화면: https://play.therookielab.app/assets/shots/home.webp

참고한 구조는 로비의 이어하기/새로하기/시설/상점, 행동 선택 후 수치 결과 표시, 체력/컨디션을 보며 경기일에 경기로 넘어가는 흐름이다. 언더독은 기존 기준 문서의 4주 × 3슬롯 월간 일정과 MMA 규칙을 유지한다. 야구 게임의 그래픽, 선수, 고유 문구, 화면 구성의 세부 디자인을 사용하지 않았다.

이번 버전 배경과 캐릭터는 생성한 오리지널 픽셀 아트이며, 캐릭터는 행별 4프레임 복싱/달리기/웨이트와 계산대/수면/멘탈 포즈를 묶었다. 움직임·장면 전환·게이지 보간·복수 캐릭터 배치는 Godot 코드로 구현한다.
