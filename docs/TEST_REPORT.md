# v0.2 테스트 결과

엔진 Godot 4.6.3 stable official, Linux x86_64 개발 환경.

## 로직

`tests/test_core.gd`: 4,756개 검사, 실패 0.

기존 생성·경제·나이·피로·성장·경기·저장·백업 복구 검사에 다음을 추가했다.

- 경기 월 도달/초과 시 월 진행 거부, 실패 시 입력 불변.

- 오래된 P0 리포트 호환, 손상된 타임라인 거부.
- 유효 은퇴·LP 한 번 지급·시설 LP 차감·시설 성장 효과·새 선수에게 보존·은퇴 선수 진행 차단.
- 150개월 연속 진행과 저장 크기, 경기 표본 6,400회 검사 유지.

로비/이어하기, 비활성 실제 구매, 명예의 전당/시설 진입, 생성, 카드 편집과 실제 회복 미리보기, 월 진행 취소, 움직이는 장면과 게이지, 알바/회복 장면 전환, 배속/건너뛰기 중복 보상 방지, 경기 월 버튼/직접 호출 차단, 경기 후 재개, 수동/재실행 저장, 540×960·360×800 표시를 검사한다. 버튼 신호와 선택 변경을 자동 호출한 테스트이며 실제 Android 터치/키보드는 미검증이다.

## 개발 서버

`python -m unittest server.test_server -v`: 8개 시나리오 통과.

익명 계정 분리, 서버 권한 계산, 경기일 차단, 재화/승패 조작 제출 거부, 동일 요청 재전송/충돌/동시 실행, 실제 구매 미연결 시 캐시 미지급, 테스트 검증기 경계/대기 결제 거부/중복 영수증/다른 계정 재사용 차단, 서버 회복 수치와 시설 권한을 검사한다.

`tests/test_online.gd`: 실제 HTTP로 Godot ↔ 개발용 FastAPI 서버를 연결한 12개 검사 통과. JSON 왕복 수치 비교 허용 오차는 0.000001. 서버 세션·선수 생성·월 진행·동일 규칙 미리보기·회복 타임라인·경기일 거부·경기 후 재개·임의 현금 제출 거부를 검사한다.

구매 테스트는 신뢰할 검증기의 입력/출력 경계 테스트이며 Google Play와 실제로 결제한 테스트가 아니다.

## 배포와 미검증

Windows 공식 x86_64 release 템플릿으로 내보내고 PE 형식/내장 PCK를 검사한다. 같은 프로젝트의 Linux release도 내보내 실제 시작을 검사한다. 소스 ZIP은 깨끗한 사본에서 가져오기와 로직 테스트를 수행한다. 파일 무결성과 최종 빌드 결과는 `BUILD_VERIFICATION.txt`에 기록한다.

Windows OS 직접 실행, Windows 코드서명/SmartScreen 해결, Android APK/실기기, 운영 서버/도메인 배포, 영구 로그인·계정 복구, 실제 Google 영수증 검증·결제·환불, 운영 부하/보안 검증은 아직 수행하지 않았다.
