# Windows에서 v0.2 실행하기

1. GitHub 안내의 **UNDERDOG_P0_v0.2_Windows.zip**을 클릭해 다운로드합니다.
2. 받은 ZIP을 오른쪽 클릭 → **모두 압축 풀기 → 압축 풀기**로 풉니다.
3. 풀린 폴더의 **UNDERDOG_P0.exe**를 더블클릭합니다. Godot 설치는 필요 없습니다.
4. 첫 화면은 로비입니다. **새로 선수 키우기**를 클릭해 이름·스타일·트렁크 색상을 고르고 시작합니다.
5. 기존 저장이 있으면 **이어서 진행하기**를 누릅니다. 이전 P0와 저장 폴더를 유지하므로 기존 선수를 이어갈 수 있습니다.

## 일정과 회복

- 아래 **일정** 탭을 클릭합니다. 위쪽이 1~4주, 세 줄이 주요/보조/생활입니다.
- 바꾸고 싶은 카드를 누릅니다. 행동을 고르면 장면과 **최대 회복량 / 실제 회복량 / 피로 전후**를 미리 볼 수 있습니다.
- **이 행동 적용**을 누르면 일정에 저장됩니다. 보조는 성장·피로·회복이 55%입니다.
- 피로가 3밖에 남지 않았다면 회복 최대 18인 휴식도 실제로는 3만 회복합니다.
- 아래로 내려 월말 예상과 회복 게이지를 확인한 뒤 **이 일정으로 한 달 시작 → 한 달 시작**을 누릅니다.
- 훈련·알바·휴식 장면과 게이지가 순서대로 재생됩니다. **속도 ×1/×2**, **결과 바로 보기**를 사용할 수 있습니다.
- 한 달 결과를 한 번 저장한 뒤 재생하므로 건너뛰거나 중간에 게임을 닫아도 보상이 중복 지급되지 않습니다.

## 경기일

- 두 달을 육성하면 첫 경기일에 도달합니다. 홈에 **오늘은 경기일**이 표시됩니다.
- 이제 다음 달 일정은 진행할 수 없습니다. **경기장으로** 또는 아래 **경기** 탭을 누릅니다.
- 상대와 내 활력을 확인하고 전략을 고른 뒤 **옥타곤에 입장하기 → 경기 시작**을 누릅니다.
- 결과에서 승패, 라운드별 체력, 수당을 확인합니다. 자세한 내용은 **상세 경기 로그**를 누릅니다.
- 경기 후 다음 출전까지 3개월 동안 다시 일정을 진행합니다. 오래된 저장에서 예정 월이 이미 지났어도 먼저 경기를 처리해야 합니다.

## 명예의 전당과 훈련소

- 홈 오른쪽 위 **로비**로 돌아갑니다.
- **명예의 전당**에서 은퇴 선수 기록을 봅니다. 18개월 + 공식 경기 3회 이후 **현재 선수 은퇴 정산**을 할 수 있습니다.
- 은퇴 정산으로 받은 LP를 **훈련소 강화**에서 사용합니다. 복싱·레슬링·주짓수 3단계이며 성장 보너스가 실제 훈련에 적용됩니다.
- 새 선수를 시작해도 정산한 명예의 전당·LP·시설은 유지됩니다. 선수 개인의 나이·현금·스탯·전적은 다시 시작합니다.
- 유효 은퇴 전에 새 선수를 시작하면 해당 선수의 LP 보상은 받지 못합니다.

## 온라인과 실제 결제의 현재 상태

정식 게임의 방향은 온라인입니다. v0.2에는 서버 코드와 연결 기능을 추가했고 개발 서버와의 실제 통신을 테스트했습니다. **운영 서버는 아직 배포하지 않았습니다.** 따라서 기본 실행은 '개발 테스트 · 정식 서버 미연결'로 표시됩니다.

Google Play 개발자 계정이 없으므로 **캐시 상점 구매 버튼은 비활성화**되어 있습니다. 실제 돈이 청구되거나 캐시가 임의로 지급되지 않습니다. 가격·영수증 검증·스토어 연결은 이후 개발자 계정을 준비한 뒤 추가해야 합니다.

개발자가 운영 서버를 준비하면 로비의 **온라인 서버 연결**에서 주소를 입력해 연결할 수 있습니다. 이 설정을 플레이 테스트 사용자가 직접 준비할 필요는 없습니다. 온라인 계정은 현재 익명 게스트 형태이며 영구 계정/기기 이전은 아직 없습니다.

## 저장과 Windows 경고

로컬 테스트 저장 위치는 이전과 같습니다.

`%APPDATA%\Godot\app_userdata\UNDERDOG MMA P0\`

- `career_v1.json`: 로컬 개발 테스트 선수
- `career_v1.json.bak`: 이전 정상 저장
- `online_cache_v1.json`: 서버 연결 시 별도 기기 캐시

기존 JSON과 백업 파일을 임의로 지우지 마세요. 게임을 닫고 두 파일을 다른 폴더에 복사하면 별도로 보관할 수 있습니다.

이 실행 파일은 여전히 디지털 서명이 없는 첫 테스트 빌드입니다. Windows 보호 경고가 이번 UI 수정으로 해결된 것은 아닙니다. 경고가 나오면 화면의 정확한 문구를 전달해 주세요. SmartScreen의 미확인 앱 경고와 바이러스 탐지는 구분해 확인해야 합니다.

## Godot에서 직접 실행하려면

1. **UNDERDOG_P0_v0.2_Godot_Project.zip**을 다운로드하고 압축을 풉니다.
2. https://godotengine.org/download/windows/ 에서 Godot 4.6.3 Standard Windows 64비트를 받아 압축을 풉니다.
3. Godot를 더블클릭하고 **Import/가져오기**에서 프로젝트 폴더의 **project.godot**을 선택합니다.
4. **Import & Edit/가져오기 및 편집**을 누르고 처음 가져오기가 끝날 때까지 기다립니다.
5. 오른쪽 위 **▶ 프로젝트 실행**을 클릭합니다. 키보드 **F5**로 실행해도 됩니다.

이 방법은 직접 게임 소스를 실행하는 방법이며 악성코드 경고를 무조건 우회하라는 안내가 아닙니다. Windows OS에서의 직접 실행 검증은 아직 수행하지 않았습니다.
