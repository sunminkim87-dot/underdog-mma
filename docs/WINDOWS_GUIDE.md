# Windows에서 시작하기 — 코딩 필요 없음

## A. 완성된 실행 파일로 플레이하기 (권장)

1. 제공된 `UNDERDOG_P0_Windows.zip`을 다운로드합니다. Windows 10/11 64비트 PC 기준입니다.
2. 파일 탐색기에서 다운로드한 ZIP을 **마우스 오른쪽 버튼 → 모두 압축 풀기 → 압축 풀기**로 풉니다. ZIP 안에서 바로 실행하지 마세요.
3. 압축을 푼 폴더의 `START_HERE.html`을 더블클릭하면 그림이 있는 이 안내가 열립니다.
4. 같은 폴더의 **`UNDERDOG_P0.exe`를 더블클릭**합니다. 이 방법은 Godot 설치가 필요 없습니다.
5. 세로 게임 창이 열리면 이름을 입력하고 기본 스타일과 트렁크 색상을 고릅니다.
6. 필요하면 마우스 휠을 아래로 내려 **‘18세 선수로 시작하기’**를 클릭합니다.
7. 창이 작거나 아래 내용이 보이지 않으면 가운데 내용 부분에서 마우스 휠로 내립니다. 아래 4개 탭은 고정되어 있습니다.

실행 파일은 개발용이며 디지털 서명이 없습니다. Windows에서 차단되거나 실행 오류가 나오면 창의 정확한 문구를 개발자에게 전달해 주세요. 모든 PC의 실행을 검증한 빌드는 아닙니다.

## B. 첫 경기까지 플레이하기

1. 아래 **‘일정’** 탭을 클릭합니다.
2. 1~4주의 주요·보조·생활을 각각 선택합니다. 처음에는 위 **‘균형’** 버튼을 눌러 기본 일정으로 시작해도 됩니다.
3. 스크롤을 내려 4주 아래 **‘월말 예상’**에서 현금과 피로를 확인합니다.
4. **‘이 일정으로 한 달 진행’ → 확인창의 ‘한 달 진행’**을 클릭합니다. 훈련 결과 창을 확인한 뒤 **‘확인’**을 누릅니다.
5. 같은 방법으로 한 달을 더 진행합니다. 선수 생활 **2개월**이 되면 첫 경기에 나갈 수 있습니다.
6. 아래 **‘경기’** 탭을 눌러 상대의 스타일·능력치와 내 피로를 확인합니다.
7. 코너 전략을 고릅니다. 처음에는 **‘균형’**을 사용해도 됩니다.
8. 아래로 내려 **‘옥타곤에 입장하기’ → ‘경기 시작’**을 클릭합니다.
9. 결과 창에서 스크롤하면 각 라운드의 상세 로그를 볼 수 있습니다. **‘확인’** 후 기록 탭에서도 다시 열 수 있습니다.
10. 다음 경기는 출전한 달로부터 **3개월 후**입니다. 그동안 훈련·알바·휴식을 반복합니다. 경기를 미뤄도 됩니다.

## C. 현금·피로를 관리하기

- 현금이 부족하면 각 주의 **‘생활’ → 편의점 알바 / 배달 알바**를 늘리세요. 수입과 피로가 함께 늘어납니다.
- 피로가 높으면 생활에서 **‘충분한 휴식’**, 훈련에서 **‘휴식 / 회복’**, 또는 상단의 **‘회복’** 일정을 고르세요.
- 매달 생활비 28만원 + 체육관비 8만원이 나갑니다. 훈련비는 별도입니다.
- 기본 균형 일정은 매달 약 16만원씩 현금이 줄어듭니다. 장기 진행에는 알바를 더 넣어야 합니다.
- ‘월말 비용 부족’이 나오면 그 달은 아직 진행되지 않았습니다. 일정을 바꾸면 계속 플레이할 수 있습니다.
- 훈련비 부족으로 특정 훈련을 못 했다면 해당 주 로그에 휴식 대체가 표시됩니다.
- **‘훈련별 성장·피로 안내’**에서 각 행동의 효과를 볼 수 있습니다.

## D. 저장과 불러오기

1. 생성, 일정 변경, 월 진행, 경기 후 자동으로 저장됩니다. 아래 상태줄에서 저장 완료를 확인합니다.
2. 원하는 때 **‘선수’ → 아래로 스크롤 → ‘저장’**을 클릭할 수도 있습니다.
3. 게임 창의 **X**를 눌러 닫고 `UNDERDOG_P0.exe`를 다시 더블클릭합니다. 저장된 선수가 자동으로 열립니다.
4. 게임 중 **‘선수’ → ‘불러오기’**로 디스크에 저장된 상태를 다시 읽습니다. 자동 저장 기능 때문에 오래된 시점으로 되돌리는 기능은 아닙니다.
5. **‘기록’ → 아래로 스크롤 → ‘저장 폴더 열기’**로 실제 저장 위치를 엽니다.
6. 백업하려면 게임을 닫고 그 폴더의 `career_v1.json`과 `career_v1.json.bak`을 다른 폴더로 **복사**합니다. `.bak`은 두 번째 저장 이후 생깁니다.
7. 복원하려면 게임을 닫고 보관한 파일을 같은 이름으로 저장 폴더에 복사한 뒤 다시 실행합니다.

저장 위치: `%APPDATA%\Godot\app_userdata\UNDERDOG MMA P0\`

주 저장이 손상되면 이전 정상 `.bak`에서 복구합니다. 복구 시 이전 진행 상태일 수 있습니다. ‘새 선수 만들기’는 확인 후 현재 슬롯을 교체합니다. 먼저 별도 복사로 보관하세요. 실행 파일과 Godot 편집기로 실행한 게임은 같은 Windows 계정에서 같은 저장 슬롯을 사용합니다.

## E. Godot에서 프로젝트 열기 (프로젝트 확인용)

1. 별도 `UNDERDOG_P0_Godot_Project.zip`도 다운로드하고 **모두 압축 풀기**로 풉니다.
2. 브라우저에서 **https://godotengine.org/download/windows/** 를 엽니다.
3. **Godot 4.6.3 Standard**의 Windows 64비트 버전을 받습니다. 이 프로젝트는 C#/.NET을 사용하지 않습니다. 다른 버전은 별도로 검증하지 않았습니다.
4. Godot ZIP도 압축을 푼 후 `Godot_v4.6.3-stable_win64.exe`를 더블클릭합니다.
5. Godot 프로젝트 관리자에서 **‘가져오기 / Import’ → ‘찾아보기 / Browse’**를 누릅니다.
6. 압축을 푼 `UNDERDOG_P0_Godot_Project` 폴더 안의 **`project.godot`**을 선택하고 **‘가져오기 및 편집 / Import & Edit’**을 누릅니다.
7. 처음 폰트와 그래픽을 준비하는 동안 잠시 기다립니다.
8. 편집기 오른쪽 위 **▶ ‘프로젝트 실행 / Run Project’**를 클릭합니다. 키보드 **F6가 아니라 F5**로 실행해도 됩니다.
9. 실행 화면이 편집기에 작게 들어가면 실행 창의 **분리 / Make Floating** 아이콘으로 별도 창을 열어 볼 수 있습니다.
10. 소스 파일을 편집할 필요 없이 게임 화면에서 플레이합니다.

플레이만 할 때에는 A의 실행 파일이 더 간단합니다. Windows 실행 파일 재생성은 Godot의 **편집기 → 내보내기 템플릿 관리**에서 동일 버전 템플릿을 설치한 뒤 **프로젝트 → 내보내기 → Windows Desktop → 프로젝트 내보내기**로 수행합니다. Android 내보내기는 현재 결과물에 포함하지 않았습니다.

## F. 자동 테스트와 문제 전달

- 일반 플레이에는 필요 없습니다. 프로젝트의 `tools/Run_Core_Tests.bat`을 더블클릭하면 Godot 실행 파일을 고르는 창이 열립니다. 설치한 Godot EXE를 고르면 로직 테스트가 실행됩니다.
- 결과는 프로젝트의 `tests/core_results.json`, 콘솔 출력과 `tests/core_console.log`에 남습니다. 테스트 저장은 실제 선수 파일과 다른 이름을 사용합니다.
- 테스트가 실행되지 않으면 Godot 4.6.3인지 확인하고 파일 선택 창에서 게임 EXE 대신 **Godot 편집기 EXE**를 골라 주세요.
- 화면 자동 테스트는 개발 환경에서 수행했습니다. 소스의 `tests/test_ui.gd`와 7장 스크린샷을 함께 제공합니다.
- 보고할 내용: 실행 환경(Windows 버전), 누른 버튼 순서, 예상한 결과, 실제 결과/오류 문구, 가능하면 해당 저장 파일. 경기 문제는 기록 화면의 **시드·전략·선수 생활 개월**도 적어 주세요.
